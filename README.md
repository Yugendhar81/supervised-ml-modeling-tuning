# Supervised Classification / Regression Modeling & Tuning

## Objective
To build supervised machine learning models for classification and regression, evaluate their performance, and improve them using hyperparameter tuning.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn

## Tasks Performed
1. Load sample datasets.
2. Split data into training and testing sets.
3. Train a classification model.
4. Train a regression model.
5. Tune model hyperparameters using GridSearchCV.
6. Evaluate performance using suitable metrics.

## Models Used
- Logistic Regression for classification
- Random Forest Regressor for regression

## Evaluation Metrics
- Classification: Accuracy
- Regression: Mean Squared Error and R² Score

## How to Run
Install dependencies:

`pip install -r requirements.txt`

Run the program:

`python supervised_ml.py`

## Conclusion
This project demonstrates supervised learning, model evaluation, and hyperparameter tuning using Scikit-learn.
